SHAFIA PORTFOLIO

Cara menjalankan:
1. Ekstrak folder shafia-portfolio.
2. Simpan foto profil sebagai assets/foto.jpg.
3. Buka index.html dengan browser (Chrome/Edge).
4. Edit teks di index.html, warna/layout di style.css, dan interaksi di script.js.

Catatan: Google Fonts memerlukan koneksi internet. Form kontak membuka aplikasi email (mailto), tidak mengirim ke server.
